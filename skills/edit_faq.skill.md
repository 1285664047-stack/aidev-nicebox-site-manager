# 修改已有独立 FAQ

本流程只修改 FAQ 管理中的独立记录，不处理文章或产品内部的 `faq_items`，也不修改页面模板。

## 定位目标

1. 用户提供编号时精确搜索；只提供问题或答案关键词时模糊搜索。
2. 多条结果时展示编号、问题、语言、分类和显示状态，让用户选择，禁止自行猜测。
3. 确定目标后读取最新详情，保留返回的一致性摘要供写入使用，不向用户显示该摘要。

## 可修改字段

只支持问题、答案、分类、语言、发布时间、显示状态和排序。支持单字段或一次修改多个字段；未要求修改的字段必须保持不变。

- 清空答案时明确传空字符串。
- 取消分类时使用无分类；非零分类必须属于当前账号且与最终语言一致。
- 发布时间必须是 `YYYY-MM-DD HH:mm:ss`，不能传空值。
- 显示状态只控制该 FAQ 显示或隐藏，不发布网站。
- 用户要求修改其他字段时明确说明不支持，不得静默忽略或假报成功。

## 摘要、确认与保存

1. 只展示本次字段的“当前值 -> 新值”，并说明其他内容保持不变。
2. 单字段和多字段都只取得一次明确确认；目标或参数变化后必须重新展示摘要并确认。
3. 用户确认后调用 `nicebox_update_faq`，只传用户明确要求的字段。
4. 内容在确认期间发生变化时，本次不得覆盖；重新读取详情、重新展示差异并重新确认。
5. 修改成功后只报告实际修改字段和保存结果，不询问 SEO、Schema、预览或整站发布。

通信方式、工具参数、一致性摘要和回退过程保持静默。
